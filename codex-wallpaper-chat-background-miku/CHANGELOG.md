# 更新记录

## 1.0.1

- 兼容 Codex 26.1021 的深色主题状态：页面已为暗色时，不再调用已移除的旧设置接口。
- 原生主题接口报错时仍加载动态壁纸，并将具体原因记入日志。
- 增加主题兼容性回归测试；保留原有暗色、透明度和启动联动设置。
- 修复启动中转时 Electron 新建子进程导致的取消：核对父进程身份和创建时间，仅接纳本次新启动实例的子进程，继续保护其他实例和 PID 复用。
- 容忍子进程在身份检查后自行退出；仍明确报告对存活进程的访问拒绝。

## 1.0.0

- 全窗口动态背景、暗色外观、边缘羽化和磨砂输入区。
- 保留原 Codex 启动入口；新增启动监视器与隐藏登录启动项。
- 现有会话基线保护、精确进程身份校验、原启动参数转发及防重复中转。
- 默认不创建额外桌面或开始菜单图标，并清理旧版工具自己的冗余图标。
- 安装前验证 Node、配置和 MP4；支持只保存配置、不启动进程。
- v6 星光叠层直接取高分辨率视频帧，640×360 仅分析透明度。
- 新后台程序支持文件停止信号；权限不足时明确报告，不伪称成功。
- 个人本地素材更新为 4K60 播放版和 12K60 母版，均为 234 帧、3.90 秒。
- 增加 Markdown 格式的完整 TXT 安装须知与本地 Codex 操作指令。
